我是一个硬件工程师，现居深圳，本科毕业即工作目前也工作了快6年的老登。这个开始写这个博客的初衷只是为了将自己平常看到的一些内容做一个整理（虽然因为我是个懒狗可能更新并不会很频繁，且硬件的技术内容平常经常需要画图，我是真的很讨厌画图，更新频率可能无法保证），把之前写的一些笔记内容整理成博客的形式，毕竟大学时期也曾经尝试过用Hexo之类的建站，只是流程的话还是比较熟悉的。

另外，虽然我是一个硬件工程师，平常也经常会用写代码作为兴趣（虽然很菜，仅熟悉各类环境的安装及卸载，偶尔会写一些兴趣类的项目）。因此目前内容上可能会有较多的软件配置方面（作为半名LUG+半个Vimer，虽然是neovim+微软大战代码，虽然因为硬件有很多软件是仅限Windows，可能我个人目前还没过折腾的年纪）、算法之类的内容掺杂。

目前由于这个博客内容较少目前由于这个博客内容较少，目前暂时不打算将这个内容单独租服务器+买域名托管，所以目前还是将这个博客托管到GitHub Pages。这个博客使用 Hugo + Stack 搭建，由于对前端的知识仅限能够看懂 Html + CSS + 粗浅学过一点的TS和JS，且在大学时期尝试过前端之后实在难以静下心写那一个一个的box和对象，所以这个博客目前是尽可能~~简陋~~简单的思路，能不改的配置绝对不改，所以基本是默认设定的样子，只是改一些字体或者背景颜色什么的。或许可能在文章数量太多之后用超过GitHub Pages的最大限制后，会考虑重构一下，但现在就这样就好。

现在这份工作也已经干了快2年，越来越多的工作，每次开会都在阴阳人让你加班的领导，就算完成了工作也不可能高的绩效，总感觉工作快干到头了。虽然现实总是这么让人火大，不管是我自己亦或是看到这个隐藏在互联网以南角落的自我介绍（？）的你，希望彼此不管工作或生活如何，至少能够有那么一丝享受自己喜欢东西的时间，至少能够在百忙之中能够享受到生活的一点美好。

写的没什么主题，与其说是我和这个博客的介绍，不如说只是一个快被工作挤占掉生活的老登的一点碎碎念。如果你能看到这那十分感谢（虽然应该也不会有什么人看吧），希望你生活开心，也希望你我能够发现或重新找回电路或变成带给我们的乐趣。
